# Performance Scalability And Observability Prompt

```text
Bir performance engineer ve observability reviewer gibi davran.

ParkChargeEV performans, ölçeklenebilirlik ve gözlemlenebilirlik durumunu denetle.

İncele:
- App Router dynamic/static route dengesi
- admin dashboard ve route prefetch davranışı
- DB query yoğunluğu
- network chatty endpointler
- büyük component/page dosyalarının startup etkisi
- request lifecycle içinde sync/blocking işler
- caching ve revalidation ihtiyacı
- image/asset optimizasyonu
- logging, health endpoint, metrics/tracing izi
- gerçek performans ve algılanan performans farkı
- Vercel serverless soğuk başlangıç riski

Rapor formatı:
1. Kapsam
2. Darboğaz Riski Olan Alanlar
3. Scale Riskleri
4. Backend Performance Riskleri
5. Frontend Performance Riskleri
6. Observability Olgunluğu
7. Skor Kartı
8. Kısa ve Orta Vadeli İyileştirmeler
```
